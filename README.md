# CENTRAL SENAC

Sistema web e blog de portal de notícias desenvolvido como projeto final da matéria de TI.

## Equipe

 - Vitor Filgueira - QA / Testes
 - José Luciano - Back-end
 - Gabriel Costa - Líder
 - Matheus Vinícius - Front-end

## Tecnologias

 - Node.js
 - TypeScript
 - Express
 - EJS
 - Jest

## Como executar

```bash
npm install
npm run dev
```
## Como rodar os testes

```bash
npm test
```
